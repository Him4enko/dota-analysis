# Dota 2: анализ жалоб на систему поведения

Воспроизводимый Python-проект для исследования публичных обсуждений Behavior Score,
Conduct Summary, Communication Score, Low Priority, Overwatch и репортов в Dota 2.
В репозитории есть код сбора и анализа, закэшированные ответы источников, очищенный корпус,
ручная проверочная разметка, графики и подробный отчёт.

**Главный результат текущего среза:** калиброванная доля жалоб среди найденных релевантных
обсуждений — **50,8%** (95% ДИ 42,7–58,8%). Статистически значимого роста тренда не обнаружено.
Это оценка публичных обсуждений, а не доля недовольных игроков и не проверка правильности
конкретных наказаний.

**Подробный отчёт:** [`reports/REPORT.md`](reports/REPORT.md) · **Графики:** [`reports/figures/`](reports/figures/).

## Установка

Требуется Python **3.10 или новее**.

### Windows PowerShell

Из корня проекта:

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m pip install -e .
```

Если PowerShell запрещает активацию окружения, можно запускать интерпретатор напрямую:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip install -e .
```

### macOS / Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m pip install -e .
```

## Быстрый запуск без сети

В репозитории сохранён HTTP-кэш, поэтому основной результат можно пересчитать без обращений
к интернет-ресурсам:

```bash
python scripts/collect.py --offline
python scripts/import_cached_arctic.py
python scripts/analyze_all.py
python scripts/verify.py
python -m unittest discover -s tests -v
```

`--offline` запрещает сетевые запросы. `import_cached_arctic.py` просматривает только
локальные файлы в `data/cache/` и добавляет комментарии, которые были в сохранённых ответах,
но не попали в первоначальную выгрузку.

## Новый сбор из источников

```bash
python scripts/collect.py
python scripts/import_cached_arctic.py
python scripts/analyze_all.py
python scripts/verify.py
python -m unittest discover -s tests -v
```

Сбор можно ограничить источниками:

```bash
python scripts/collect.py --only players,github,steam
python scripts/collect.py --only arctic
python scripts/collect.py --only dota2ru,serp
```

Поддерживаемые этапы: `players`, `github`, `steam`, `arctic`, `dota2ru`, `serp`, `rss`.
При HTTP 429/403 программа прекращает запросы к ограничившему хосту на время cooldown и
продолжает другие этапы. Ошибочные ответы не маскируются и не подменяются данными другого
источника. Контакт для исследовательского User-Agent можно задать переменной окружения
`DOTA_RESEARCH_CONTACT`.

## Что получится после запуска

- `reports/REPORT.md` — подробный отчёт на русском: методы, ограничения, статистика и ссылки
  на графики;
- `reports/figures/*.png` — 9 графиков: квартальная доля жалоб, онлайн, платформы, темы,
  годы, патч-события, покрытие и валидация;
- `data/processed/corpus.csv` — релевантные записи с источником, URL и предсказанной меткой;
- `data/processed/documents_classified.csv` — весь очищенный корпус;
- `data/processed/analysis.json` — числа отчёта в машиночитаемом виде;
- `data/dota_analysis.sqlite` — локальная база, создаваемая при сборе и исключённая из Git.

Проверка `scripts/verify.py` независимо пересчитывает количество релевантных записей, число
жалоб, долю, интервал Уилсона, разбивку по источникам и наличие графиков.

## Текущий результат и ограничения

- Ручная проверочная выборка содержит 120 документов, распределённых пропорционально между
  источниками. Оценка среди найденного релевантного корпуса — 50,8% (95% ДИ 42,7–58,8%).
- Автоматический классификатор имеет ограниченную чувствительность; метрики взвешены по
  текущей доле источников. Подробности и матрица ошибок приведены в отчёте, раздел 6.2.
- После стандартизации по платформам значимого временного роста не выявлено. Результат
  чувствителен к покрытию источников и не доказывает причинность.
- Из запланированных ячеек Reddit 93,1% не ответили из-за таймаутов Arctic Shift; данные Reddit
  покрывают только часть месяцев. Дополнительно использованы 755 комментариев из уже сохранённых
  ответов старых запусков.
- Полные тексты получены только для части тем Steam; Google, Яндекс и DuckDuckGo ограничили
  автоматизированный доступ, а часть выдачи Bing оказалась нерелевантной.
- Ручная разметка выполнена одним аннотатором. Анализ описывает найденные публичные сообщения,
  а не доказывает правоту или неправоту жалоб и не представляет всех игроков Dota 2.
